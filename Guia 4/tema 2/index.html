2.6 Descifra las sombras

Valor de box-shadow ¿Qué se ve?
0 4px 12px rgba(0,0,0,.2) Sombra suave hacia abajo, efecto de elevación ligera.
0 0 0 3px #2563eb Anillo azul sólido alrededor del elemento, sin desenfoque.
inset 0 0 10px #000 Sombra interior oscura, efecto hundido o cóncavo.
10px 10px 0 #111 Sombra dura desplazada (estilo cómic o retro), sin desenfoque.
0 0 20px 5px #22d3ee Halo luminoso cian alrededor del elemento, efecto neón o glow.
