4.6 ¿Qué se puede animar?

Propiedad ¿Se anima? Observaciones
opacity Sí Animación suave y eficiente (GPU).
transform Sí Animación eficiente (GPU), ideal para movimiento.
width (100px → 300px) Sí Funciona, pero recalcula el layout (más costoso).
height (0 → auto) No No se puede animar a auto. Alternativa: usar max-height o transform: scaleY().
display (none → block) No No se puede animar. Alternativa: usar opacity + visibility.
background-color Sí Transición suave entre colores.
font-size Sí Funciona, pero puede afectar el layout.
top (con position) Sí Funciona, pero transform: translateY() es más eficiente.
