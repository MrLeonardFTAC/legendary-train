3.5 Estructura de carpetas y capas

css/
├── main.css
├── base/
│   ├── reset.css
│   └── tipografia.css
├── layout/
│   └── cuadricula.css
├── componentes/
│   ├── boton.css
│   └── tarjeta.css
└── utilidades/
    └── utilidades.css

El orden de carpetas va de lo más general (reset, base) a lo más específico (utilidades). Las capas evitan conflictos de especificidad.

3.6 Clasificar clases BEM

Clase Tipo Corrección (si es incorrecta)
.menu__item Elemento Correcto
.menu__item--activo Modificador Correcto
.menu__item__enlace Incorrecto Usar .menu__enlace (no anidar elementos)
.card.title Incorrecto Usar .card__title (doble guion bajo)
.btn--large Modificador Correcto (pero debe usarse con .btn)
.form__input--error Modificador de elemento Correcto
.sidebar-widget-title Incorrecto Usar .widget__titulo (BEM con doble guion bajo)

3.9 Refactoriza tu proyecto

Ejemplo de refactorización: antes usabas #menu a.activo con !important, ahora usas .menu__enlace--activo con especificidad baja (0,1,0).

Antes (alta especificidad)

#menu ul li a.activo { color: blue !important; }

Después (BEM, especificidad baja)

.menu__enlace--activo { color: blue; }
