Comparación de enfoques

Criterio CSS + BEM Tailwind Bootstrap
Líneas de CSS escritas ~40 líneas 0 (solo clases) 0 (solo clases)
Tiempo hasta terminar Medio (15-20 min) Rápido (5-10 min) Muy rápido (3-5 min)
Control sobre el diseño Total Alto (con @theme) Medio (variables + overrides)
Aspecto único Sí, 100% propio Sí, con personalización No, se "nota" que es Bootstrap
Facilidad para otros devs Media (hay que leer el CSS) Alta (clases autoexplicativas) Muy alta (documentación oficial)
Conclusión:
  • CSS + BEM: Ideal para proyectos con identidad visual única y equipos que valoran el control total.
  • Tailwind: Perfecto para desarrollo rápido con diseño personalizado, cuando el equipo conoce el sistema de utilidades.
  • Bootstrap: Excelente para prototipos, dashboards internos o proyectos donde la velocidad importa más que la originalidad visual.
