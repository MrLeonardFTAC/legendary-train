2.6 Comandos de Sass (referencia)

Comando ¿Qué hace?
npm install -g sass Instala Sass globalmente en tu sistema.
sass estilos.scss estilos.css Compila un archivo SCSS a CSS una sola vez.
sass --watch scss:css Vigila la carpeta scss y recompila automáticamente al guardar.
sass --style=compressed estilos.scss estilos.min.css Genera CSS minificado (sin espacios ni comentarios) para producción.
sass --no-source-map estilos.scss estilos.css Compila sin generar el archivo .map de depuración.
